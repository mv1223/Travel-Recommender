# TravelAI | Premium Luxury Travel Ecosystem

A high-end, production-grade travel platform built with **Vanilla JavaScript**, **Tailwind CSS**, and **GSAP**. 

## 🚀 Instant Run
This project is designed to run **WITHOUT** any server, backend, or build step. 

1. Download/Clone the repository.
2. Simply double-click **`index.html`** in your browser.
3. Done! The entire ecosystem is live.

## ✨ Premium Features
- **AI Recommendation Engine**: Client-side scoring logic in `components/recommendation.js`.
- **AI Trip Architect**: Multi-step itinerary generator in `pages/planner.html`.
- **Real-time Search**: Instant filtering across 1,000+ destinations in `pages/destination.html`.
- **User Dashboard**: Persistence via `localStorage` for saved trips and favorites.
- **Cinematic UI/UX**: Powered by GSAP, AOS, and Tailwind CSS for smooth animations and glassmorphism.

## 📂 Project Structure
- `/data`: Contains massive JS datasets for destinations, hotels, and more.
- `/pages`: Full-featured HTML pages for Dashboard, Planner, and Search.
- `/components`: Modular JS components for Cards and AI Logic.
- `/assets`: Images and icons.

## 🛠️ Built With
- **Tailwind CSS** (via CDN)
- **GSAP** (GreenSock Animation Platform)
- **Lucide Icons**
- **Vanilla JavaScript** (ES6+)
- **LocalStorage API**
